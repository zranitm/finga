# OD-07. Which marketplace model?

- **Area:** Economy
- **Decision:** OD-07. Which marketplace model?
- **Default:** C. Fixed-price listings first, order book later
- **Status:** Open

## Options

- **A.** Fixed-price listings.
- **B.** An order book with buy and sell orders per item type.
- **C.** A first, B later.

## Affects

F3, F5, and the Economy page.
