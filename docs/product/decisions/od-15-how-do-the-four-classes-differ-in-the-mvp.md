# OD-15. How do the four classes differ in the MVP?

- **Area:** Progression
- **Decision:** OD-15. How do the four classes differ in the MVP?
- **Default:** A. Basic attack style and stat growth only; no ammo, no MP cost for basic attacks
- **Status:** Open

## Options

- **A.** Each class has its own basic attack style (Warrior: close-range melee; Thief: fast short-range strikes; Bowman: long-range shots; Magician: ranged magic) and its own stat growth per level. Skills arrive with C5 (P1).
- **B.** Same as A, plus one or two signature skills per class in the MVP. This pulls part of C5 into P0.

## Sub-questions

- Do Bowmen need ammo (arrows) to attack?
- Do Magicians spend MP on basic attacks?
- Can any class use any weapon, or are weapons class-locked?

## Affects

A2, C2, C5, D3, and the Progression and Combat pages.
