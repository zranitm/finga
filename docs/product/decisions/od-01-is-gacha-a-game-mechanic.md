# OD-01. Is gacha a game mechanic?

- **Area:** Gacha
- **Decision:** OD-01. Is gacha a game mechanic?
- **Default:** A. No gacha mechanic
- **Status:** Open

## Options

- **A.** No. It came from the old project name (Infinite Gacha), which is now Finga.
- **B.** Gacha draws as a core feature.
- **C.** No gacha, but endless content instead, such as endless dungeon floors.

## Affects

G1 and the Gacha system page. B could add a whole feature group and change the economy.
