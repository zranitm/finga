# OD-20. How do players control the character?

- **Area:** Overview
- **Decision:** OD-20. How do players control the character?
- **Default:** C. Keyboard only, two presets
- **Outcome:** C. Keyboard only. Attacks go the way the character faces; the mouse is only for menus. Two presets: Classic (arrows) and WASD. Full remapping stays P2.
- **Status:** Decided

## Options

- **A.** Keyboard only with arrow keys; attacks go the way the character faces.
- **B.** WASD plus mouse, with attacks aimed at the cursor.
- **C.** Keyboard only like A, with two presets: Classic (arrows) and WASD.

## Why C

- Keeps the genre's feel and keeps aiming out of the combat rules, which matters with four classes to balance.
- Players used to WASD still get a familiar layout.
- Mouse aiming suits 3D games better than a 2D side-scroller.

B2, B6, and the Screens and controls page.
