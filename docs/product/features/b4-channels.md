# B4. Channels

- **Feature:** B4. Channels
- **Group:** B. World and movement
- **Priority:** P1
- **Status:** Draft

**Story:** As a player, I can pick a channel and switch channels, so crowded maps stay playable.

## Acceptance

- Each map exists in several independent channels.
- Players see only those in the same map and channel.
- Switching channels keeps the character's state and party.
