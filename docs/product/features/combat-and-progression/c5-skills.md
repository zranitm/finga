# C5. Skills

- **Feature:** C5. Skills
- **Group:** C. Combat and progression
- **Priority:** P1
- **Status:** Draft

**Story:** As a player, I can use class skills that cost MP and have cooldowns.

## Acceptance

- Each skill has an MP cost, a cooldown, and an effect.
- MP regenerates over time.
- Skills can be assigned to keys on a skill bar.
