# C1. Mobs

- **Decisions:** OD-12
- **Feature:** C1. Mobs
- **Group:** C. Combat and progression
- **Priority:** P0
- **Status:** Draft

**Story:** As a player, I fight mobs that appear, move around, and attack me.

## Acceptance

- Mobs appear at set spots up to a maximum per map, wander, and hurt players on contact.
- Defeated mobs come back after a while.
- Every player on the map sees the same mobs in the same places.
