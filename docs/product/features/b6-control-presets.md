# B6. Control presets

- **Decisions:** OD-20
- **Feature:** B6. Control presets
- **Group:** B. World and movement
- **Priority:** P0
- **Status:** Agreed

**Story:** As a player, I can choose between Classic (arrow keys) and WASD controls, so the game fits how I like to play.

## Acceptance

- Two presets are available in Settings: Classic and WASD.
- The chosen preset applies right away and is kept the next time I log in.
- Attacks always go the way the character faces; no mouse aiming.
