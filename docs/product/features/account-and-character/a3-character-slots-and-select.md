# A3. Character slots and select

- **Decisions:** OD-09
- **Feature:** A3. Character slots and select
- **Group:** A. Account and character
- **Priority:** P1
- **Status:** Draft

**Story:** As a player, I can have several characters and pick one before entering the world.

## Acceptance

- The character list shows each character's name, level, and class.
- Creating a character beyond the slot limit is not possible.
