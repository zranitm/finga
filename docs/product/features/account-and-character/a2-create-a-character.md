# A2. Create a character

- **Feature:** A2. Create a character
- **Group:** A. Account and character
- **Priority:** P0
- **Status:** Draft

**Story:** As a player, I can create a character and enter the world in the starting town.

## Acceptance

- Pick a name. There is no class to choose: every character starts as a Beginner and picks a class later (C8).
- Character names are unique and follow naming rules (length, allowed characters).
- A new character starts at level 1 in the starting town, with the Beginner's starting stats, skills, and gear.

Systems → Classes and skills and Systems → Progression
