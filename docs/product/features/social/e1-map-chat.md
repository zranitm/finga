# E1. Map chat

- **Feature:** E1. Map chat
- **Group:** E. Social
- **Priority:** P0
- **Status:** Draft

**Story:** As a player, I can chat with everyone in the same region, or map, and channel. In a large region (B10) the General tab reaches the whole region's channel.

## Acceptance

- Messages appear in the chat box's General tab and as a bubble above the speaker.
- A player who sends messages too fast is muted for a short time.
