# E2. Whispers

- **Feature:** E2. Whispers
- **Group:** E. Social
- **Priority:** P1
- **Status:** Draft

**Story:** As a player, I can send a private message to another online player by name, on any map or channel.

## Acceptance

- Only the sender and the recipient see the message.
- Whispering an offline or unknown name shows a clear notice.
