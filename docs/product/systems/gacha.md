# Gacha

> ⏸️ **Undefined.** Depends on OD-01: is gacha a game mechanic? (It came from the old project name, Infinite Gacha.)

## Questions to answer if gacha becomes a mechanic

- What can be drawn: equipment, cosmetics, consumables?
- What does a draw cost? In-game currency only, since real money is a non-goal.
- What are the drop rates, and how are they shown to players?
- Is there pity: a guaranteed rare result after a number of draws without one?
- How does it fit the economy: is it a currency sink, and can drawn items be sold on the marketplace?
- Is there a limit on draws per day?
