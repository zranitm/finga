# Finga

A browser-based 2D side-scrolling MMORPG-lite: four classes, parties of up to 4, and a player-driven marketplace. A portfolio project for backend and distributed-systems work.

Repository: `finga` (formerly named Infinite Gacha).

**Where things are**

- **Product:** what the game is and how it plays. Start with Overview.
- **Tech:** how it's built, starting with the High-level design.

Each section owns its own decisions: Product decisions under Product, Tech decisions under Tech.
