# TD-05. Demo hosting: a VPS, or a platform such as Fly.io?

- **Area:** Operations
- **Decision:** TD-05. Demo hosting: a VPS, or a platform such as [Fly.io](https://fly.io)?
- **Default:** A VPS
- **Status:** Open

## Options

- **A.** One VPS running Docker Compose.
- **B.** A managed platform.

## Why the default

It matches the local Compose setup exactly, and running Kafka is simpler on a box you control.

## Affects

HLD section 14.
